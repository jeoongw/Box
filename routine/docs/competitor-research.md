# 루틴 앱 경쟁 조사 (2026-11-15)

목표: 다운로드 상위 루틴 앱의 장단점을 실제 사용자 리뷰로 확인하고, "바쁜 직장인, 단순한 사용감"에 맞는 것만 골라 우리 앱에 적용한다.

## 1. 대상 앱 선정

### 기준
- **Google Play**: 스토어가 공개하는 설치 수 구간(10M+, 5M+ …) 순. 같은 구간이면 리뷰 수 순.
- **App Store**: Apple은 다운로드 수를 공개하지 않는다. 대신 미국 스토어 **평가 수**를 규모의 대리 지표로 썼다.
- 루틴/습관 앱만 포함. 일반 할 일 앱(TickTick, Todoist)과 감정 일기(Daylio)는 제외.
- 조회 시점: 2026-11-15, 각 스토어 페이지에서 직접 확인.

## 2. 리뷰 수집 방법과 한계
- 각 스토어 페이지가 기본으로 보여주는 리뷰를 읽었다. Google Play 앱당 3개(15개), App Store 앱당 20개(100개), 합계 약 115개.
- 스토어 페이지는 "도움이 됨" 순으로 노출되어 **긍정 리뷰가 많이 섞인다**. 대량 수집은 하지 않았으므로 빈도를 통계로 해석하면 안 된다. 반복되는 주제를 찾는 용도로만 썼다.
- 보조 자료: 습관 앱 이탈 원인을 다룬 공개 글(아래 출처).

## 3. 사용자가 좋아하는 점 (장점)

| 주제 | 근거 리뷰 (요약) | 앱 |
|---|---|---|
| 실패해도 혼내지 않음 | "습관을 못 해도 부정적인 피드백이 없다", "놓쳐도 깎아내리지 않고 격려한다" | Productive, Finch |
| 못 한 일이 다음 날로 이어짐 | "끝내지 못하면 다음 날 목록에 남아서 잊지 않는다" | Finch |
| 한눈에 보기(위젯) | "위젯만 봐도 끝낸 것과 안 끝낸 것이 보인다" | Habit Tracker, Structured |
| 하루 흐름이 실시간으로 보임 | "시간이 지나면서 블록이 채워져 얼마나 남았는지 보인다" | Structured |
| 무료로도 충분, 일회성 결제 | "무료 버전만으로 쓸만하다", "평생 이용권이 있다", "일회성 결제가 훨씬 싸다" | Structured, HabitNow, Habit Tracker |
| 유연한 반복 | "하루 20분, 주 4시간처럼 다양하게 설정" | Habit Tracker |

## 4. 사용자가 싫어하는 점 (단점)

| 주제 | 근거 리뷰 (요약) | 앱 |
|---|---|---|
| 유료 유도, 광고, 체험판 함정 | "프리미엄도 팝업 광고 같다", "체험 취소했는데 4번 결제 시도", "프로모션을 사면 7일 체험이 사라짐", "설정 질문에 다 답하니 그제야 유료" | Fabulous, Me+ |
| 앱 자체가 광고처럼 변함 | "테마가 개봉 영화 홍보뿐, 광고에 돈을 내는 기분" | Finch |
| 순서가 뒤죽박죽 | "시간순 정렬이 자꾸 수동으로 돌아간다", "입력한 순서대로 안 보여 찾아다녀야 한다", "이름만 바꿔도 순서가 바뀐다" | Me+, Productive |
| 알림이 늦거나 엉뚱함 | "휴대폰을 켤 때 알림이 한꺼번에 온다", "이미 완료했는데 알람이 울린다", "알림이 항상 늦다" | Me+, HabitNow |
| 오늘이 아닌 루틴은 수정 불가 | "일요일 루틴을 목요일에 고치려니 '오늘에 집중하라'며 막는다" | Me+ |
| 첫 설정이 오래 걸림 | "루틴을 원하는 순서로 만드는 데 너무 오래 걸렸다" | Me+ |
| 연속 기록 압박 | "연속 기록이 깨지면 죄책감을 준다. 끌 수도 없다" | Productive, 이탈 분석 글 |
| 기록 유실 | "휴대폰을 떨어뜨려 기록을 다 잃었다" | Habit Diary, 이탈 분석 글 |
| 밤늦게 끝나는 하루 | "자정 넘어 한 일이 다음 날로 찍힌다. 하루 시작 시각을 정하고 싶다" | HabitNow |
| 반복 주기 부족 | "격일, 3일마다 같은 반복이 없다" | Habit Diary |

## 5. 우리 앱과 비교

| 항목 | 우리 앱 현재 | 판단 |
|---|---|---|
| 유료/광고 | 없음 | **강점 유지.** 앞으로도 넣지 않음 |
| 순서 | 항상 시간순 고정 | **강점 유지** |
| 실패 압박 | 연속 기록 없음 | **강점 유지** |
| 완료 후 알람 | 완료한 루틴은 알람 안 울림 | **강점 유지** |
| 오늘이 아닌 루틴 수정 | **불가** (오늘 목록에만 보임) | Me+와 같은 문제. **고친다** |
| 앱을 닫으면 알람 없음 | 페이지가 열려 있어야 울림 | 가장 큰 약점. **우회책 추가** |
| 기록 유실 | 브라우저에만 저장 | **백업/복원 추가** |
| 자정 넘은 루틴 | 23:30 이후 루틴이 날짜 경계에서 꼬임 | **하루 시작 시각 추가** |
| 바쁜 날 | 못 하면 "지남"으로 남음 | **오늘만 건너뛰기 추가** |

## 6. 적용할 것 (우선순위)

| # | 개선 | 해결하는 문제 | 단순함 영향 |
|---|---|---|---|
| 1 | **전체 루틴 보기**: 요일과 상관없이 모든 루틴을 보고 수정 | 오늘이 아닌 루틴 수정 불가 | 목록 아래 링크 하나 |
| 2 | **캘린더로 내보내기 (.ics)**: 반복 일정 + 알림으로 휴대폰 기본 캘린더에 등록 | 앱을 닫으면 알람이 안 울림 | 설정 안에 버튼 하나 |
| 3 | **백업 파일 저장 / 불러오기** | 기기 변경 시 기록 유실 | 설정 안에 버튼 둘 |
| 4 | **하루 시작 시각** (기본 새벽 4시) | 자정 넘은 루틴이 다음 날로 찍힘 | 설정 안에 시간 하나 |
| 5 | **오늘만 건너뛰기**: 진행률 분모에서 빠지고 알람도 안 울림 | 바쁜 날의 죄책감 | 수정 시트에 버튼 하나 |
| 6 | 홈 화면 추가 지원 (앱 아이콘, 이름) | 매번 주소 입력 | 화면 변화 없음 |

## 7. 일부러 넣지 않는 것
- 펫, 게임화, 연속 기록, 배지: 재미는 있지만 압박과 복잡도를 키운다 (Finch, Productive 리뷰).
- 첫 실행 설문, AI 코치, 콘텐츠 추천: 설정 시간과 팝업 피로 (Me+, Fabulous 리뷰).
- 통계 대시보드: 바쁜 사용자에게 우선순위가 낮다.
- 격일/주 N회 반복: 요청은 있지만 입력 화면이 복잡해진다. 사용자 요청이 생기면 재검토.
