# 보상 설계 (행동과학 근거)

원칙: 보상은 습관을 시작하게 돕고, 습관이 자리 잡으면 줄여 간다. 물질적 보상, 연속 기록, 순위는 쓰지 않는다.

| 기능 | 동작 | 근거 |
|---|---|---|
| 다시 시작 인정 | 전에 한 적이 있는 루틴인데 가장 최근 예정일(건너뛴 날 제외)을 놓쳤다면, 오늘 체크할 때 "다시 시작했어요"라고 알린다 | 대규모 헬스장 실험에서 운동을 빠진 뒤 돌아온 사람에게 준 보상이 효과가 컸다 (Milkman 등, 2021, Nature) |
| 주간 횟수 | 연속 기록 대신 "이번 주 3/5". 월요일부터 일요일까지, 건너뛴 날은 분모에서 뺀다 | 하루 빠져도 습관 형성에 큰 영향이 없다 (Lally 등, 2010). 연속 기록이 끊기면 아예 그만두는 경향이 있다 |
| 작은 즉각 보상 | 체크할 때 짧은 두 음, 15ms 진동, 체크 원이 살짝 튀는 움직임. 설정에서 끌 수 있고, 동작 줄이기 설정을 따른다 | 하는 동안 느끼는 즉각적 만족이 지속을 더 잘 예측한다 (Woolley & Fishbach, 2017). 진행 피드백은 내적 동기를 해치지 않는다 (Deci, Koestner, Ryan, 1999) |
| 자리 잡음 | 처음 완료한 지 8주가 지났고, 최근 8주 예정일의 85% 이상을 완료한 루틴에 "자리 잡음" 표시. 알람이 켜져 있으면 한 번만 "알람 없이 해볼까요?"라고 묻는다 | 습관은 반복과 상황 신호로 굳어지며, 자리 잡으면 보상 없이도 유지된다. 보상과 알림을 줄여 의존을 낮춘다 |

## 기준값
- 자리 잡음: 기간 56일, 완료율 85%, 최소 예정일 8일 (주 1회 루틴도 판정 가능)
- 다시 시작: 최근 60일 안에서 가장 최근 예정일을 확인

## 일부러 넣지 않은 것
포인트, 배지, 펫, 순위, 연속 기록. 할 때마다 받는 물질적 보상은 내적 동기를 떨어뜨릴 수 있고(과잉정당화 효과), 끊기는 순간 압박이 된다.
