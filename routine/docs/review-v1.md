# v1 검토 결과 (design-critique, accessibility-review, ux-copy, dataviz)

대상: 바쁜 직장인. 목표: 열자마자 "지금 뭘 해야 하지?"에 답하고, 한 번 탭으로 체크.

## Design Critique

### Overall Impression
24시간 원형 시계는 아름답지만 화면 절반을 차지하고, 실제 행동(체크)은 오른쪽 목록과 상시 노출된 추가 폼 사이에 묻혀 있다. 가장 큰 개선 기회는 "지금 할 일"을 맨 위로 올리고 나머지를 걷어내는 것.

### Usability
| Finding | Severity | Recommendation |
|---|---|---|
| 첫 화면에서 다음 할 일이 작은 회색 부제로만 보임 | 🔴 Critical | 상단에 "지금 할 일" 카드 + 큰 완료 버튼 |
| 추가 폼이 항상 펼쳐져 있어 목록보다 시선을 끔 | 🟡 Moderate | 하단 "루틴 추가" 버튼 → 바텀시트 |
| 요일 7개를 매번 하나씩 눌러야 함 | 🟡 Moderate | 매일 / 평일 / 주말 / 직접 선택 프리셋 |
| 루틴 수정 불가, 삭제는 편집 모드에서만, 되돌리기 없음 | 🟡 Moderate | 행을 누르면 수정 시트, 삭제 후 토스트에서 되돌리기 |
| 놓친 루틴과 남은 루틴이 구분되지 않음 | 🟡 Moderate | 지난 시간은 "지남" 표시 |
| 원형 시계의 점(18px)을 눌러 체크하는 숨은 기능 | 🟢 Minor | 시계 제거, 진행률 막대로 대체 |
| 주간 링 7개는 정보량 대비 공간이 큼 | 🟢 Minor | 제거 |

### Visual Hierarchy
- **What draws the eye first**: 원형 시계. 행동이 아니라 장식이 먼저 보임.
- **Reading flow**: 날짜 → 시계 → (오른쪽) 목록 → 폼. 모바일에서는 시계를 지나 한참 스크롤해야 목록.
- **Emphasis**: 완료 버튼보다 시계와 폼이 강조됨.

### Consistency
| Element | Issue | Recommendation |
|---|---|---|
| 버튼 문구 | "완료" / "5분 뒤 다시" / "루틴 추가" / "편집" 혼재 | 동사형 통일, 결과 토스트와 같은 단어 |
| 색 | 금색이 장식(호)과 상태(완료) 두 역할 | 상태용 진한 호박색 하나로 |

### What Works Well
- 테마(안개빛 + 남색 + 금색)와 고운바탕 제목의 차분한 인상
- 시간순 목록, 알람 창의 큰 시간 표시
